# 智能车辆检测上位机系统

基于 **Qt 6 / C++17 / SQLite** 的 Windows 桌面应用，按墨刀原型实现，包含 10 个功能页面与全部批注优化点。

## 功能页面

| 页面 | 功能 |
|------|------|
| 检测模式 | 单车/多车模式、手持探测仪与地面传感器分隔显示、同时检测车辆数、模拟检测 |
| 检测记录 | 按车牌/探测仪/结果/日期查询、导出 CSV、今日统计、最近七日柱状图 |
| 设备管理 | 在线/离线状态、模拟上线、移除（弹窗确认）、重新上线自动恢复 |
| 账户管理 | 三类账号、密码哈希、权限分配（含参数配置）、启用/停用 |
| 司机管理 | 司机增删改查 |
| 车辆管理 | 车辆字段管理、载重、关联司机 |
| 授权管理 | 授权文件生成/导入（密文）、到期校验、授权信息显示 |
| 操作日志 | 记录关键操作 |
| 参数配置 | admin 全部可改；管理员/普通用户仅基础信息与检测参数可改；需重启项提示重启 |
| 间隔设置 | 检测页面重新初始化间隔、恢复设置说明 |

## 批注优化点落实情况

1. **检测模式**：手持探测仪与地面传感器之间按需显示分隔线；无传感器则不显示。
2. **设备管理**：保存曾连接设备并显示在线/离线；移除后不再显示，下次上线自动恢复。
3. **权限**：普通用户默认仅「检测记录、间隔设置」；分配权限弹窗含「参数配置」；三类账号（admin/管理员/普通用户），admin 密码非默认弱口令。
4. **车辆**：字段调整（能源类型/车型/车型等级/类型/载重）；与司机双向关联。
5. **授权**：进入单车/多车模式前校验到期，未授权弹窗可跳转授权管理；支持授权文件导入与信息显示；授权信息密文存储。
6. **检测记录**：新增参数（温湿度/速度/轴数）展示；统计图表；日期查询使用 `date()` 比较，结束日期包含当天，修复数据缺失。
7. **参数配置**：admin 与管理员/普通用户显示不同；需重启参数保存后提示并重启。
8. **间隔设置**：增加界面恢复设置说明。

## 默认账号

- 管理员：`admin` / `Admin@2026!Strong`（首次运行自动创建，密码非默认弱口令）
- 其他账号：由 admin 在「账户管理」中创建并分配权限

## 数据库

文件：`AppDataLocation/hmi_system.db`（Windows 通常为 `C:\Users\<用户名>\AppData\Local\Example\QtSqliteDemo\hmi_system.db`）

## 构建与安装包

与前文相同：推送 `v*` 标签触发 GitHub Actions，自动生成 `QtSqliteDemo-1.0.0-setup.exe` 并发布到 Releases。

本地构建：

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="C:\Qt\6.6.0\msvc2019_64"
cmake --build build --config Release
```
